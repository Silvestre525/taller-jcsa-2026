2. Contenido y Objetivos
Breve Descripción:
Taller práctico en el que cada participante despliega una aplicación web completa usando únicamente planes gratuitos de servicios en la nube. Partiendo de una app simple (una lista de tareas con inicio de sesión), se recorre el camino completo del desarrollo a producción: front moderno, API en Python con FastAPI, base de datos Postgres, autenticación, envío de correos y monitoreo. Al finalizar, cada estudiante tendrá su propia app funcionando en internet y sabrá cómo replicar el proceso en sus proyectos.
Ejes temáticos / Contenidos principales:
Despliegue de un front moderno en Cloudflare Pages
API en Python con FastAPI desplegada en Cloudflare Workers
Base de datos Postgres serverless con Neon
Autenticación de usuarios con Clerk
Envío de correos transaccionales con Resend
Monitoreo y observabilidad con Grafana Cloud
3. Audiencia y Requisitos
Público Objetivo: Estudiantes de carreras de informática, sistemas o afines, y quienes quieran llevar sus proyectos a producción sin costo.
Conocimientos Previos Requeridos: Programación básica (idealmente algo de Python y JavaScript), nociones de Git/GitHub y de qué es una API.
Requisitos Técnicos / Materiales: Laptop propia con conexión a internet, Node.js, Python 3.12+ y uv instalados, y cuentas gratuitas creadas previamente en GitHub, Cloudflare, Neon, Clerk, Resend y Grafana Cloud (se enviará una guía antes del taller).
